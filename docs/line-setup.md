# ตั้งค่า LINE OA แจ้งเตือนลูกค้า

ตั้งค่าทั้งหมดในโปรแกรมที่ **⚙️ ตั้งค่า → LINE OA** (ไม่ต้องใส่ค่าใน Vercel)

## หลักการทำงาน
- ลูกค้าแอด LINE OA ของร้าน แล้วพิมพ์ **เลขที่เอกสาร** → ระบบผูก LINE กับลูกค้าคนนั้นอัตโนมัติ
- ร้านส่งข้อความแจ้งสถานะได้จากหน้ารายละเอียดงาน หรือให้ส่งอัตโนมัติเมื่อเปลี่ยนสถานะ
- **ระบบค้นหาเดิมใน LINE ยังใช้ได้**: ใส่ Webhook URL ของระบบเดิมในช่อง “Webhook URL ของระบบเดิม” ระบบนี้จะส่งต่อทุกข้อความให้ (LINE OA ตั้ง Webhook ได้ที่เดียว)

---

## ขั้นที่ 1 — จด Webhook เดิมไว้ก่อน (สำคัญ ถ้ามีบอทเดิม)
1. เปิด https://developers.line.biz/console/ ล็อกอินด้วยบัญชี LINE ที่ดูแล OA
2. เลือก Provider → เลือก Channel ของ OA (ประเภท Messaging API)
3. แท็บ **Messaging API** → หัวข้อ **Webhook settings** → คัดลอก **Webhook URL** ที่มีอยู่ เก็บไว้
   (ถ้าว่าง = ไม่มีระบบเดิม ข้ามได้)

> ถ้ายังไม่มี Channel: เปิด https://manager.line.biz → เลือก OA → **ตั้งค่า (Settings) → Messaging API → เปิดใช้งาน Messaging API** → เลือก/สร้าง Provider แล้วกลับมาที่ developers.line.biz

## ขั้นที่ 2 — เอาคีย์ 2 ตัว
1. แท็บ **Basic settings** → **Channel secret** → คัดลอก
2. แท็บ **Messaging API** → ล่างสุด **Channel access token (long-lived)** → **Issue** (ถ้ามีอยู่แล้วใช้ค่าเดิมได้) → คัดลอก

## ขั้นที่ 3 — ใส่ในโปรแกรม (ยังไม่เปลี่ยน Webhook)
1. เว็บ CRM → **⚙️ ตั้งค่า → LINE OA**
2. วาง Channel access token และ Channel secret
3. โหมด: เลือก **🧪 จำลอง** ก่อน
4. ช่อง “Webhook URL ของระบบเดิม” → วางค่าที่จดไว้จากขั้นที่ 1
5. ถ้าบอทเดิมตอบเลขที่เอกสารอยู่แล้ว → **ปิด** “ตอบกลับลูกค้าเมื่อเชื่อมสำเร็จ”
6. **บันทึกการตั้งค่า LINE** → ต้องขึ้นชื่อ OA ของร้าน และโควตาข้อความ

## ขั้นที่ 4 — เปลี่ยน Webhook มาที่ระบบนี้
1. หน้าตั้งค่า → คัดลอก **Webhook URL** (`https://crm-service-center.vercel.app/api/line/webhook`)
2. developers.line.biz → แท็บ **Messaging API** → Webhook URL → **Edit** → วาง → **Update** → **Verify** (ต้องขึ้น Success)
3. เปิด **Use webhook** ให้เป็น ON
4. ทดสอบว่าบอทเดิมยังตอบได้ตามปกติ (ถ้าไม่ตอบ → ตรวจช่อง Webhook URL ของระบบเดิมในขั้นที่ 3)

## ขั้นที่ 5 — ทดสอบ
1. ใช้ LINE ของคุณเอง แอด OA ร้าน → พิมพ์เลขที่เอกสารของงานทดสอบ
2. เปิดงานนั้นในเว็บ → การ์ด **💬 แจ้งลูกค้าทาง LINE** ต้องขึ้น “✅ ลูกค้าเชื่อม LINE แล้ว”
3. กด **ทดลองส่ง (จำลอง)** → ข้อความขึ้นในประวัติ (ยังไม่ส่งจริง)
4. พร้อมแล้ว → หน้าตั้งค่า เปลี่ยนเป็น **📤 ส่งจริง** → บันทึก → ลองส่งอีกครั้ง ข้อความต้องเข้า LINE

---

## หมายเหตุ
- **โควตา:** แพ็กเกจฟรีของ LINE OA ส่งข้อความ push ได้จำนวนจำกัดต่อเดือน — ดูจำนวนที่เหลือในหน้าตั้งค่า
  การตอบกลับ (reply) ตอนลูกค้าพิมพ์เลขที่เอกสาร ไม่นับโควตา
- **ความปลอดภัย:** ถ้าเลขที่เอกสารผูกกับ LINE อื่นอยู่แล้ว ลูกค้าต้องพิมพ์ “เลขที่เอกสาร + เบอร์โทร 4 ตัวท้าย” เพื่อเปลี่ยน
- แอดมินยกเลิกการเชื่อม LINE ของลูกค้าได้ที่หน้าลูกค้า
- ข้อความอัตโนมัติจะไม่ส่ง (และไม่ถือเป็น error) ถ้าลูกค้ายังไม่เชื่อม LINE
